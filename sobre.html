Sobre as equipes

Quem fez este projeto acontecer?

Conheça as equipes que construíram o projeto Evolução das lâmpadas: quem desenvolveu o site e quem realizou a pesquisa e forneceu as informações sobre a história da iluminação.

Contexto acadêmico

Este site foi desenvolvido como parte de um Projeto Integrador, reunindo estudantes dos cursos de Sistemas de Informação e Engenharia Elétrica. A proposta conecta a pesquisa sobre a evolução das lâmpadas ao desenvolvimento de uma apresentação digital educativa, colocando em prática os conhecimentos das duas áreas.

Objetivo do projeto

Entender o passado para iluminar o futuro

Este projeto apresenta a evolução das lâmpadas e mostra como os avanços tecnológicos transformaram a iluminação, relacionando ciência, consumo de energia e sustentabilidade.

Por trás do projeto

Como desenvolvemos o projeto

O projeto uniu pesquisa, criatividade e tecnologia para apresentar a evolução da iluminação e transformar aprendizados em uma experiência digital.

Ferramentas utilizadas

Durante o desenvolvimento, cada ferramenta apoiou uma etapa do trabalho, enquanto a equipe ficou responsável pelas escolhas, pela revisão do conteúdo e pelos testes do site.

Criação e pesquisa

  • Canva: materiais visuais.
  • Codex e Claude.ai: dúvidas, icones e imagens ilustrativas.

Desenvolvimento

  • Visual Studio Code: arquivos HTML, CSS e JavaScript.
  • Bootstrap 5.0: layout responsivo.

Publicação e prática

  • Vercel: publicação do site na internet.
  • Pesquisa, programação e trabalho em equipe.
